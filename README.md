# Slotlife Information Hub

슬롯생활과 연계된 카지노·슬롯 정보 가이드를 정리한 공개 GitHub 저장소입니다.

- Main site: https://slotlife1.com/
- GitHub Pages: `https://YOUR_GITHUB_ID.github.io/slotlife-information-hub/`
- Completed Google Sites guides: **25**

## Repository purpose

이 저장소는 슬롯, 바카라, 룰렛, 블랙잭, 포커 및 카지노 공통 주제의 공개 Google Sites 가이드를 사람이 탐색하기 쉽게 정리하고, GitHub Pages에서 일반 HTML 링크로 연결하기 위해 구성되어 있습니다.

> 검색엔진의 크롤링·색인은 보장되지 않습니다. 대상 페이지는 공개 상태여야 하고 검색엔진의 기술 요구사항을 충족해야 합니다.

## First setup

1. 저장소 이름을 `slotlife-information-hub`로 생성합니다.
2. 저장소는 `Public`으로 설정합니다.
3. 이 패키지의 파일을 저장소 루트에 업로드합니다.
4. `_config.yml`의 `YOUR_GITHUB_ID`를 실제 GitHub 아이디로 변경합니다.
5. `Settings → Pages → Build and deployment → Source → Deploy from a branch`를 선택합니다.
6. Branch는 `main`, folder는 `/(root)`를 선택하고 Save 합니다.
7. 자세한 설명은 [`SETUP.md`](SETUP.md)를 확인하세요.
